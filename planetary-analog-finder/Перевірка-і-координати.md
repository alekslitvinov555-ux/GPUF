# Global Planetary Analog Finder — перевірений тестовий запуск

Відкрий `web/index.html` у браузері. У цій копії вже є `web/data.js` із кліматичними середніми NASA POWER за 2001–2025 роки. Інтернет потрібен для бібліотек, супутникових підкладок і назв місць.

У блоці Target coordinates натисни на назву, щоб повернути відповідну точку до центру глобуса. Кожна точка має статус і пряме посилання на NASA.
## Що перевірено

- Завантаження всіх 10 параметрів NASA POWER для чотирьох тестових квадратів у районах Атаками, Сахари, України й Антарктиди. Після маски суші залишилося 892 клітинки із 11 показниками, включно з похідними.
- У Chromium спрацювали 2D-карта, 3D-глобус, помаранчевий шар, чотири профілі, зміна й скидання ваг, список кандидатів, картки та перемикання знімків Марса й Місяця. У фінальному проході JavaScript-помилок не було.
- У тестовій вибірці Атакама опинилася в топ 14,2% для екваторіальних районів Марса. Сухі долини Мак-Мердо опинилися в топ 5,4% для профілю підповерхневого льоду Марса і в топ 5,1% для місячного південного полюса. Результати залежать від меж тестової вибірки.
- Альбедо відсутнє для 84 із 892 клітинок, здебільшого на межах тестових квадратів. Формула підставляє для пропущеного показника часткову схожість 0,5. Глобальне завантаження та валідація всього списку аналогів залишаються неперевіреними.
- Маска суші проєкту на його повній сітці 0,5° × 0,625° дає 69 052 вузли суші до фільтрації за наявністю кліматичних даних. Це перевірка розміру сітки, яку не слід подавати як кількість клітинок у готовому глобальному наборі.
- Поточні профілі ранжують середовища за кліматичними та похідними показниками. Окремі геологічні приклади в Україні пояснюються вручну. Схили, мінералогія, освітленість і доступність ресурсів у формулу не входять.

До підрахунку перцентилів вилучено 35 клітинок, центри яких лежать у РФ. Фільтр діє на тестові й глобальні збірки, експорт та демоверсію. Межі РФ визначає Natural Earth 1:10m (версія 5.1.1, українська версія кордонів). Крим лишається Україною. Супутникова підкладка NASA показує всю Землю.

Станом на 14 листопада 2026 року NASA описує Moon Base як проєкт для району біля південного полюса й оцінює кілька перспективних ділянок. Для посадки Artemis IV NASA публікує дев’ять районів-кандидатів. Маркери на сайті охоплюють п’ять таких районів та окрему довідкову ділянку Shackleton Rim. [Moon Base FAQ](https://www.nasa.gov/moon-base-frequently-asked-questions/) · [Artemis IV](https://www.nasa.gov/mission/artemis-iv/) · [Перелік дев’яти районів у повідомленні NASA](https://www.nasa.gov/news-release/nasa-provides-update-on-artemis-iii-moon-landing-regions/)

[Завдання NASA Space Apps Challenge 2026](https://www.spaceappschallenge.org/2026/challenges/permanent-moon-base-locations-and-mars/) просить знайти й описати нові земні аналоги майбутніх баз або посадкових районів на основі відкритих даних і показати їх на карті, у візуалізації чи в іншому інструменті. Опис залишає учасникам вибір цілей.

## Повний запуск

У папці проєкту з Python 3 виконай команди нижче. Завантаження кешується й може тривати кілька годин. Після завершення знову відкрий `web/index.html`.

```powershell
python -m pip install -r requirements.txt
python 1_download_data.py
python 2_build_dataset.py
```
