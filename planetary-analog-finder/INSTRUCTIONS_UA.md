# Як запустити (для команди PANEM_U)

> **Швидкий погляд без запуску:** двічі клацни `web/preview.html` (потрібен інтернет). Це дизайн-превʼю з демо-даними — справжня Земля, Марс і Місяць зі знімків NASA. Справжні результати аналізу з'являться в `web/index.html` після кроків нижче.

Потрібен Python 3 з інтернетом. Усі команди виконуй у папці `analog_finder` (в терміналі або в терміналі PyCharm/VS Code).

## 1. Встановити бібліотеки (1 хв)
```
pip install numpy pandas global-land-mask
```

## 2. Пробний запуск (1 хв) — перевірити, що все працює
```
python 1_download_data.py --test
python 2_build_dataset.py --test
```
Відкрий `web/index.html` у браузері. Мають бути видні шматки карти (Атакама, Сахара, Україна, Антарктида) і жовта плашка «Test mode».

## 3. Повне завантаження (≈1–1,5 год)
```
python 1_download_data.py
```
- Скрипт качає дані NASA POWER по всій планеті. NASA дозволяє ~30 запитів на хвилину, тому скрипт іде повільно і пропускає квадрати, де лише океан. Не закривай вікно і не давай ноутбуку заснути.
- Якщо впаде або напише «tiles failed», просто запусти ще раз: готові шматки збережені й не перекачуються.

## 4. Побудувати карту (1–2 хв)
```
python 2_build_dataset.py --names
```
- `--names` підтягує назви місць для «hidden gems» з OpenStreetMap (≈1 с на місце).
- В консолі з'явиться **звіт валідації** (де опинились відомі аналоги) і **топ знахідок**.
- Відкрий `web/index.html` — це і є готовий проєкт. Кнопка «3D Globe» вгорі вмикає 3D-Землю, а в кутку обертається справжній Марс/Місяць зі знімків NASA (потрібен інтернет).

## 6. Публічне посилання на проєкт (обов'язкове поле «Project»)
Найпростіше — **GitHub Pages** (безкоштовно, без реєстрації для глядачів):
1. Створи публічний репозиторій на GitHub, наприклад `planetary-analog-finder`.
2. Завантаж туди всю папку **без** `data/raw` (вона велика і не потрібна).
3. Settings → Pages → Source: `Deploy from a branch`, branch `main`, folder `/ (root)` → Save.
4. Через 1–2 хв карта буде за адресою `https://<твій-логін>.github.io/planetary-analog-finder/web/`
5. У поле **Project** — посилання на репозиторій або на цю сторінку.
